## 1 · World generation (`src/world/`)

**Health:** determinism discipline largely sound (position-seeded per-lot RNG, layout/render-space split
respected), but one genuine idempotency hole; the biggest wins are structural (Accum3D backing, centre build
still main-thread), which dwarf the micro-optimizations; duplication creeping across composers.

1. **[PERF] `meshbuild.ts:14-23,236-247` — Accum3D backs every mesh with growable `number[]` arrays.**
   Every vertex = 8 `Array.push` into boxed-double JS arrays; a detailed city runs ~20 live accumulators each
   holding whole-city vertices as `number[]`, then doubles peak memory copying to `Float32Array` in
   `geometry()`. This is the dominant generation allocation/GC hotspot. Fix: accumulate into growable typed
   arrays (doubling on overflow) directly.

2. **[WORKER] `world-manager.ts:1300-1330` — the CENTRE city still generates on the main thread** (regen stalls),
   even though `tile-build.ts` proves the pipeline is worker-safe. Blocker: `buildStreets`/`placeLandmarks`
   MUTATE the graph (`lot.builtH`, doors, variety slots, landmark tags) and the main thread reads the mutated
   graph afterward (traffic, picking, text signs, bounds). To offload, the worker must return the
   (structured-cloneable) graph too, and the main thread adopts it. Highest-value regen-latency win.

3. **[BUG] `streets.ts:220-224,194` — variety-lot caps break selective-regen idempotency.** The `nConstr<2` /
   `nParking<2` / `nGas<1` counters consume in *visit order after the region filter*, so the same lot can be a
   building in one render and a construction site in another depending on which regions were active. Also
   clusters all special lots into the first-sorted region. Fix: position-hash quota (spatial buckets) instead of
   global running counters.

4. **[PERF] `voidgrid.ts:158-162` — fade-band emit does 5 redundant point-in-polygon passes** (filter+map per
   band) over every segment. Single pass computing band index + `outside()` once, bucket directly.

5. **[PERF] `biome.ts:70,76-78` — per-scatter-point `ponds.some(pointInPolygon)`** with no bbox rejection,
   O(points × ponds × 14 verts). Precompute pond AABBs; test AABB before the polygon.

6. **[PATTERN] `layout.ts:19-26` / `elevation.ts:14-20` / `warp.ts:16-22` — three identical value-noise
   implementations.** They must stay coherent for drape/warp/terraces to line up — consolidate into one
   `valueNoise2D` in `util.ts` before they drift.

7. **[PATTERN] `streets.ts:145+`, `biome.ts:67`, `landmarks.ts:73` — `regionByBlock`/`distById`/centroid maps
   rebuilt from scratch inside every composer.** Compute once on the graph, share.

8. **[BUG] `util.ts:163-188` — `triangulate` bails silently on non-simple polygons** (`if (!ear) break`) and
   `cap()` feeds it raw `clipConvex` output (can contain near-duplicate/collinear verts) → a degenerate lot can
   silently drop a roof/floor cap (visible hole). Dedupe/collinear-filter first, or fan-fallback the residual.

9. **[PERF/BUG] `traffic.ts:209-210` — `tallestH` recomputed by full-lot scan inside `computeTraffic`** and
   silently 0 if streets didn't run for all lots (region filter) → planes cruise at ground level. Guard +
   document the cross-pass ordering.

10. **[PATTERN] `streets.ts:144` — dead `rng`** (never consumed; all uses shadowed by `lotRng`). Misleading —
    remove.

11. **[PERF] `traffic.ts:51-77` — `roadRuns` double-scans roads with `toFixed(4)` string keys.** Single pass,
    rounded numeric keys.

12. **[PERF] `elevation.ts:35-37` — the drape height field is very low frequency (`f0 = 1/(0.7R)`)** yet fully
    evaluated per vertex (8 hashes) on every centre regen. Sample on a coarse grid + bilinear per vertex.

## 2 · Services + persistence

**Health:** persistence is architecturally sound (atomic writes, params-only city, dirty-gated 3D, gzip at
rest) but the *entire save pipeline runs on the main thread* — the top WORKER opportunity in the codebase. 3D
undo is cheap (closure commands — the "snapshot deep-copies the scene" fear is unfounded); the per-action cost
is the raster snapshot readback. Sharp edges: a leaked autosave timer, depth-texture leaks, an fflate import
bug.

1. **[PERF][WORKER] `document-persistence.ts:295-357` + `raster-layer-manager.ts:1015-1029` — autosave does
   GPU→CPU readback per layer (sequential awaits), PNG-encodes, and gzips — all main-thread.** Multi-hundred-ms
   stall every 30s (and 5s after each stroke) on big documents. Readback loop, PNG encode, and gzip are all
   worker/OffscreenCanvas candidates.

2. **[PERF] `raster-texture-manager.ts:312-395` — `pushSnapshot` (the log line you see per action) is
   raster-only**, O(canvas pixels) not O(meshes): full-canvas `copyTextureToBuffer` + `mapAsync` + row-unpack +
   byte-by-byte dedup compare per paint action, retaining `maxSnapshots` uncompressed RGBA copies.

3. **[GOOD NEWS] `undo-manager-3d.ts` — 3D undo stores closure commands + per-mesh scalar snapshots (O(selected),
   not O(scene)).** No scene deep-copy per action exists on the 3D path.

4. **[BUG] `persistence-manager.ts:54-60` — `enableAutoSave()` replaces the DocumentPersistence instance without
   destroying the old one → the old `setInterval` fires forever** (doc switch/reopen), leaking timers and racing
   concurrent saves from a stale provider. Call `destroy()` first.

5. **[BUG] `interaction-service.ts:88-95,329-336` — `setDepthTextureView()` creates a new depth GPUTexture
   without destroying the previous; `reset()` has the destroy commented out.** Leaks canvas-resolution depth
   textures on every reinit/resize.

6. **[BUG] `project-package.ts:219,230,255` — unpack uses `entries[key].buffer` ignoring
   `byteOffset`/`byteLength`.** If fflate returns subarray views, imports read the wrong bytes (corrupt
   layers/GLB). Slice to owned buffers.

7. **[PERF] `document-persistence.ts:352-356,650-656` — orphan pruning does a full OPFS directory listing × 5
   dirs on EVERY save.** Prune only after actual deletions.

8. **[PATTERN] `document-persistence.ts:235-259` — no lock between texture readback and concurrent stroke
   mutation** → an interval save landing mid-stroke can persist a torn frame. Mostly hidden by the debounce.

9. **[PERF] `document-persistence.ts:448-481` — model3d/meshTextures/bakedParts load sequentially** (`await` in
   `for await`) while layers/cels are correctly `Promise.all`'d.

10. **[PERF] `interaction-service.ts:125-138` — `toWorldCoordsFromCanvas` allocates + full `mat4.invert` per
    pointer event.** The inverse only changes on pan/zoom (`worldMatrixVersion` exists) — cache it.

11. **[PERF][BUG] `mesh-picker.ts:185-191` — BVH builds synchronously on first pick** (click hitch for large
    pickable imports), and a geometry mutation without `gpuDirty` keeps a stale BVH → wrong hits.

12. **[PATTERN] `transform-controller-3d.ts:420,638,704,737,785` — drag-apply loops walk ALL meshes per
    pointermove** to find the selected handful; iterate `initialTransforms` keys instead (O(selected)).

13. **[PERF] `texture-library.ts:103-118` — every material texture stored as base64 WebP data-URL inside JSON**
    (+33% size, re-gzipped every 3D-dirty save). Store as binary sidecars like GLB/PNG.

14. **[PERF] `project-package.ts:167-176` — already-deflated PNG bytes re-zipped at level 1** — store at level 0
    like the GLB path; also export encodes run sequentially on the main thread.

15. **[IDEA] `document-persistence.ts:253-257` — `savePending` re-queue chains saves under rapid mutation**;
    collapse to a single trailing save.

## 3 · Scene-graph + cross-cutting

**Health:** read paths are well-hardened; the *mutation* paths (`removeChild`, `zIndex`/transform setters,
`isDirty` side effect) are O(N)-per-op landmines at city scale. Hygiene otherwise clean; the big cost centre is
`JSON.parse(JSON.stringify())` keyframe cloning on interactive edits. Procedural-content isolation is coherent.

1. **[PERF/BUG] `node.ts:283-291` — `removeChild` recurses the FULL subtree per removal → O(N²) city
   teardown.** After filtering `this.children` it still deep-scans every remaining child. Locate-and-splice at
   the owning parent instead.

2. **[BUG/PATTERN] `node.ts:100-103` — the `isDirty` SETTER rebuilds the local matrix as a side effect**, and
   the 2D render strategy sets `isDirty = false` after upload → rebuilds the matrix + bumps the version,
   invalidating the cache the same frame it was consumed. Two divergent clear paths exist
   (`resetDirtyFlag()` is side-effect-free). A genuine footgun.

3. **[PERF] `node.ts:90-93` — `zIndex` setter re-sorts the parent's entire child array per assignment** →
   bulk re-layering is O(N² log N).

4. **[PERF] `node.ts` transform setters double-recurse the subtree** (`updateLocalMatrix` also calls
   `markChildrenParentChainDirty`), and `Mesh3D.setPosition3D` sets x/y/z separately → **3 recursive dirty
   walks per move.** Multiplies on thin-wrapper groups over thousands of children.

5. **[PERF] `scene-graph.ts:33-47` — `findNodeById` degrades to full-tree walk; `registerNode` is called from
   exactly one place.** Register on `addChild` or drop the map pretense.

6. **[PERF] `scene3d-manager.ts:10395,10402,8048-8049,10327-10374` — `JSON.parse(JSON.stringify())` clones the
   ENTIRE keyframeTracks map on every keyframe set/undo, and full submesh materials per mesh duplicate.**
   Interactive-edit cost, not just save. Per-track structured copies instead.

7. **[PERF] `polygon.ts:38-49,179-196` — 4× `Math.min(...map())` allocations per transform tick** while
   dragging a polygon. Single-pass loop, cache until points change.

8. **[PERF] `shape.ts:358-374` — `getInverseLocalMatrix` cache is disabled (early-return commented out)** →
   allocate + invert per call; hit-testing sweeps (eraser/marquee) pay it per shape per event.

9. **[PERF] `group.ts:107-159` — `Group.recalculateSize` cache-busts every child's bbox** (~10 mat4/vec4 + two
   inversions). MeshGroup3D overrides to no-op (city safe); plain Groups pay full cost.

10. **[PERF] `shape.ts:376-389` — `getWorldSpaceCorners` allocates 4 vec4/call, cache disabled with a standing
    TODO** ("scaling handles break if I cache this") — a known unresolved correctness-vs-perf compromise.

11. **[PATTERN] keyframe deep-clones don't exclude procedural meshes** — if a city mover ever carries tracks,
    undo/keyframe ops clone them. Add a guard.

12. **[PATTERN] `live-text.ts:512,530` — untracked setTimeouts not cleared in destroy()** (only timer-hygiene
    gap found).

13. **[PATTERN] ~8 shapes spam `console.error("Matrix inversion failed")` per pointer-move** on degenerate
    matrices (zero scale). One-shot warn or silent identity fallback.

14. **[PATTERN] `node.ts:47-53` — `as any` structural probes on the hottest matrix-composition path** — a field
    rename silently falls through to "no transform". Use a typed discriminator.

15. **[IDEA] `shape.ts:425` — `toJSON` eagerly mints lazy UUIDs → first save of a large 2D scene bursts
    `crypto.randomUUID` per shape.**

## 4 · Character stack

**Health:** geometry math is solid and the known traps are fixed (VertGrid fits, skin-matrix sharing, GPU
skinning, allocation-free spring solver). The overriding weakness is **regeneration orchestration**: one body
slider tick eagerly rebuilds *everything* on the main thread.

1. **[PERF] `scene3d-manager.ts:3345-3417` — ONE body slider tick regenerates the ENTIRE character**: body +
   all 6 clothing slots (full fit passes) + hair (full spring-rig teardown/rebuild) + charms + face decal — per
   drag frame, no debounce, no param diffing. The dominant character-mode cost.

2. **[PERF] `skeleton-3d.ts:115-139` + `scene3d-manager.ts:4079-4087` — `addJoint()` is O(joints) (full
   `computeWorldMatrices` + skinMatrices realloc per call) and hair adds joints in a loop → O(joints²) per
   regen** — which fires per slider tick via #1. Build chains first, compute once.

3. **[WORKER] `body-generator.ts:1033`, `clothing-generator.ts`, `hair-generator.ts` — the generators are pure**
   (plain params + body verts in, typed arrays out, no DOM/GPU) → ideal Web Worker candidates with transferable
   buffers. The highest-leverage mitigation for #1.

4. **[PERF] `renderer-3d.ts:3652-3685` — ~9 identical `skinMatrices` uploads per posed frame** (body + garments
   + hair + decal each own a per-mesh buffer for the SAME skeleton). A per-skeleton shared skin buffer cuts it
   ~9×.

5. **[PERF] `clothing-generator.ts:952-962` — a fresh VertGrid over the same body verts is rebuilt per garment
   fit** (6× per refit). Share one grid across slots.

6. **[BUG] `scene3d-manager.ts:3355-3357` — `setBodyParams` swaps geometry/skin but leaves blend-shape
   `baseVertices` + captured rest-skin stale** → bodies with blend shapes or edit-mode history mis-evaluate
   after a body-param change.

7. **[PATTERN] `hair-generator.ts:595-673` — `buildTail`/`buildTailCards` duplicate ~60 lines of
   bezier/parallel-transport setup**; vec3/pushVert/ring helpers re-implemented across body/hair/clothing.
   A shared mesh-accum module removes hundreds of duplicated lines.

8. **[COMPUTE] spring solver + blend-shape eval are CPU per frame** — both well-optimized today; compute-pass
   candidates only if character counts grow (crowds).

9. **[PERF] `scene3d-manager.ts:3978-3993` — every hair refit re-concatenates body+garment verts and re-scans
   the head region** — per slider tick via #1.

10. **[IDEA] `scene3d-manager.ts:1480-1502` — idle animation keeps springs from ever settling** (`moving`
    forever → continuous sim+render). Fine for one hero; verify the activation gate excludes idle crowds.

11. **[PERF] `body-generator.ts:1069-1109` — two full index-buffer normal passes per gen** — fine once gen
    moves to the worker.

12. **[PATTERN] `setBodyParams` has no shallow-equality short-circuit** — re-emitting the current value pays the
    full rebuild.

13. **[VERIFIED-OK] spring state on regen/clip-switch is correctly reset** (WeakMap tips, resetSpringState on
    rebuild/truncate). No bug.

## 5 · Renderer passes + shaders

**Health:** pass orchestration is structurally sound (resize-guarded textures, destroy chains, feature
early-outs; no leaks or per-frame pipeline creation). The dominant cost is the **3D mesh uber-shader** paying
for features most pixels don't use.

1. **[PERF] `mesh3d-shaders.ts:646-650,1122-1126` — `patternMask()` ×3 + the enormous `windowsPattern()` run
   UNCONDITIONALLY per fragment on every mesh**, even with patterns off (characters/terrain/cars). The single
   largest per-pixel waste citywide. Can't be branched (fwidth uniformity) → needs compile-time variants (#2).

2. **[IDEA] One uber-shader carries ~10 runtime feature branches** (renderStyle, patMode 0-7, rim, sparkle,
   hair sheen, glass, fog, 16-light loop, PCF). Specialize pipelines by material class via marker substitution
   (the shadow-variant pattern already exists) → big ALU + occupancy win.

3. **[PERF] `outline-shaders.ts:134-147` — Sobel outline is O((2w+1)²) taps/pixel with NO early-out** (width 6
   → 169 depth taps fullscreen). Break on first edge; ring-only silhouette test.

4. **[PERF] `mesh3d-shaders.ts:1350-1355` — shadow PCF is a fixed 5×5 = 25 compare taps per lit fragment.**
   Offer 3×3 tier tied to the existing shadow quality knobs.

5. **[PERF] `post-process-pass.ts:283-297` — both full-res rgba16float bloom textures allocate even when bloom
   is OFF** (vignette-only path). Allocate lazily.

6. **[COMPUTE] `dither-engine.ts:232-296` — error-diffusion does GPU→CPU readback + WASM + writeTexture per
   composite (hard pipeline stall), allocating a fresh MAP_READ buffer each call.** Block-parallel compute
   candidate; at minimum ring-buffer the readback.

7. **[PERF] `dither-engine.ts:194-196,1046-1053` — 2 standalone queue.submit() per dithered layer per frame.**
   Share the compositor's encoder.

8. **[PERF] `bloom-pass.ts:104-159` — 4 bind groups rebuilt + an extra submit every bloom frame.** Cache by
   identity; fold into the caller's encoder.

9. **[PERF] `post-process-pass.ts:358-381` — blur bind groups recreated per invocation** (peers are already
   cached). Cache by (src,dst,step).

10. **[PERF] `mesh3d-shaders.ts:785,1243` — `envSpecular` (reflect + 9-term SH) runs for every PBR fragment
    even matte dielectrics.** Gate by metalness/F0.

11. **[PERF] `shell-renderer.ts:1762-1937` — ~10 `new Float32Array` per frame while the shell animates.** Reuse
    scratch arrays.

12. **[PERF] `gizmo-renderer.ts` (10 sites) — fresh uniform bind group per overlay sub-draw per frame.**
    Editor-only; cache per persistent buffer.

13. **[PERF] `mesh-edit-overlay-renderer.ts:289-308` — buffer + bind group churn per pointer-move during vertex
    drags.** Pre-size generously.

14. **[PATTERN] `bloom-pass.ts:271` — dead `_vBlurPipeline` state.** Remove.

15. **[PERF] `webgpu-renderer.ts:2719-2743` — SDF atlas bump walks the WHOLE scene graph per version change**
    (typing/animated text). Track dirty SDFText nodes in a set.

## Recommended attack order

### Fix-soon bugs (correctness, mostly small)
1. Autosave timer leak on doc switch (`persistence-manager.ts:54`) — §2.4
2. Depth-texture leak on canvas reinit (`interaction-service.ts:88`) — §2.5
3. fflate `.buffer` slicing on package import (`project-package.ts:219`) — §2.6
4. Variety-lot selective-regen idempotency (`streets.ts:220`) — §1.3
5. `setBodyParams` stale blend-shape/rest-skin (`scene3d-manager.ts:3355`) — §4.6
6. `isDirty` setter matrix-rebuild side effect (`node.ts:100`) — §3.2
7. Silent roof-cap drop in `triangulate` (`util.ts:163`) — §1.8

### Highest-ROI performance (in order)
1. **Character regen orchestration** — debounce + param-diff `setBodyParams`, batch hair `addJoint`, share the
   fit VertGrid (§4.1/2/5/12). Transforms character-mode sliders.
2. **Shader specialization** — strip pattern/window ALU from non-pattern materials; PCF quality tier
   (§5.1/2/4). The citywide GPU win.
3. **Autosave → worker** — readback/PNG/gzip off-thread + prune-on-delete-only (§2.1/7). Kills the 30s hitch.
4. **Accum3D typed-array backing** (§1.1) + **centre-city regen in worker** (§1.2, needs graph adoption).
5. **`removeChild` O(N²)** (§3.1) + keyframe deep-clones (§3.6) + transform-controller O(selected) (§2.12).

### Worker/compute shortlist
- Autosave pipeline (readback + PNG encode + gzip) — biggest UX win
- Character generators (pure, transferable) — enables live sliders
- Centre-city full regen (blocked only on returning the mutated graph)
- Error-diffusion dither → compute pass (removes a per-frame stall)
- Spring/blend-shape → compute — only when crowds arrive

### Verified healthy (no action)
3D undo (closure commands, O(selected)) · spring state resets · pickable/BVH discipline ·
excludeFromDocument serialization isolation · pass orchestration teardown/resize · post-streaming-campaign
hot paths (see memory notes).
