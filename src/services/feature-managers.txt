----------------------------------------------------------------------------------------------------------------
FEATURE MANAGER ARCHITECTURE
----------------------------------------------------------------------------------------------------------------
In the future, individual Feature Manager APIs will allow for modularized architecture.

Each manager is self-contained but can pull from:
ShapeManager for geometry spawning
RenderCache for GPU access
SceneGraph for spatial layout
InteractionService for zoom/pan/mouse tracking
etc...

We could support:
const board = new SalsaBoard({
  enableAI: true,
  enableFlowcharting: false,
  enableSDFText: true
});

And internally:
if (config.enableFlowcharting) {
  this.flowchartingManager = new FlowchartingManager(...);
}

Optional APIs are then only exposed when enabled.
This also helps us:
Avoid bloating minimal builds
Let users bring their own server, socket layer, etc.
Support “headless” mode for non-GPU analytics

----------------------------------------------------------------------------------------------------------------
BRIDGES - The future of AI Streaming Pipelines
----------------------------------------------------------------------------------------------------------------
Bridges will be our superpower for AI integration:
// AIStreamManager
addBridge(new PoseToShapeBridge());
addBridge(new MusicVisualizerBridge());

Each bridge:
Consumes some stream (WebSocket, mic, webcam, model)
Emits to your ShapeManager or SceneGraph
Registers itself with the AIStreamManager dispatcher

In theory, a bridge streams data directly into our application registries.

----------------------------------------------------------------------------------------------------------------
Feature Manager Architecture:
Loose coupling: You can replace a RenderStrategy, FlowchartingManager, or AI bridge without touching core.
User flexibility: Devs only import what they need (import { ShapeManager } from "@frogmarks/core").
Long-term evolution: It scales well into audio, 3D, multi-modal AI, etc.
